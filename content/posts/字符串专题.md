## 当前重点：P1308 统计单词数（待自己重做）

- 链接：https://www.luogu.com.cn/problem/P1308
- 难度：普及−
- 数据范围：文章长度 ≤ 10^6，**不能暴力嵌套，要 O(n)**

### 题目核心

给一个目标单词 + 一篇文章，统计目标词作为**独立单词**出现的次数 + 第一次出现位置（下标从 0 开始，空格也算一位）。

### 四个关键知识点（重做时对照）

1. **读行用 `getline`**：文章含空格，`cin >>` 读到空格就停。
2. **`cin >> target` 后要 `getchar()` 吃换行**：否则下面的 `getline` 读空行。
3. **统一大小写**：大写 `+32` 变小写，再比较。
4. **前后补空格判断独立单词**：`" to "` 不会匹配 `Ottoman` 里的 `to`。

### find 的用法（重点记忆）

```cpp
art.find(target);              // 从头找，返回下标
art.find(target, pos + 1);     // 从 pos+1 往后找
// 找不到返回 string::npos
```

`string::npos` = "no position" = 没找到的暗号。

### 本人在此题踩过的坑（必须记住）

| 坑 | 正确写法 |
|---|---|
| 全角冒号 `：：` | 半角 `::` → `string::npos` |
| 单等号 `if(first=-1)` | 双等号 `if(first==-1)` |
| `int` 和 `size()` 比较告警 | 先存 `int len = s.size()` |

## 当前重点：P1553 数字反转（学习中）

- 链接：https://www.luogu.com.cn/problem/P1553
- 难度：普及−（公认的「烦题」——细节多，但没算法）

### 题目核心

反转一个数（整数/小数/分数/百分数），去掉前导 0。

### 四种类型怎么切

| 类型 | 怎么找 | 左边 | 右边 |
|---|---|---|---|
| 整数 `5087462` | 没有符号 | 整个 `rev` | — |
| 小数 `600.084` | `find('.')` | `substr(0,p)` | `substr(p+1)` 小数部分 |
| 分数 `700/27` | `find('/')` | `substr(0,p)` 分子 | `substr(p+1)` 分母 |
| 百分数 `8670%` | `find('%')` | 去掉 `%` 后 `rev` | — |

### 核心逻辑：整数去「开头 0」，小数去「结尾 0」

- 整数/分子/分母/百分数：反转后去**开头** 0
- 小数部分：反转后去**结尾** 0（因为原数的前导 0 反转后跑到末尾了）

### 本题涉及的新知识点（重点记）

| 函数/写法 | 作用 | 例子 |
|---|---|---|
| `reverse(s.begin(), s.end())` | 反转字符串 | `"084"` → `"480"` |
| `s.erase(0, 1)` | 删第 0 个字符（去开头 0）| `"006"` → `"06"` |
| `s.pop_back()` | 删最后一个字符（去结尾 0）| `"480"` → `"48"` |
| `s.back()` | 取最后一个字符 | `"480".back()` → `'0'` |
| `s.substr(起点)` / `substr(起点,长度)` | 截取子串 | `"600.084".substr(4)` → `"084"` |
| 自定义函数 | 复用「反转+去0」逻辑 | `rev`、`dec` |

### 完整代码（精简版）

```cpp
#include<bits/stdc++.h>
using namespace std;

string rev(string t){                     // 反转 + 去开头 0
    reverse(t.begin(), t.end());
    while(t.size()>1 && t[0]=='0') t.erase(0,1);
    return t;
}
string dec(string t){                     // 小数部分：反转 + 去结尾 0
    reverse(t.begin(), t.end());
    while(t.size()>1 && t.back()=='0') t.pop_back();
    return t;
}

int main(){
    string s; cin >> s;
    if(s.find('%')!=string::npos)                    // 百分数
        cout << rev(s.substr(0,s.size()-1)) << "%";
    else if(s.find('/')!=string::npos){              // 分数
        int p=s.find('/');
        cout << rev(s.substr(0,p)) << "/" << rev(s.substr(p+1));
    }
    else if(s.find('.')!=string::npos){              // 小数
        int p=s.find('.');
        cout << rev(s.substr(0,p)) << "." << dec(s.substr(p+1));
    }
    else cout << rev(s);                             // 整数
}
```
