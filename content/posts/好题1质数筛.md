题目：

### **质数筛**

输入 n 个不大于 105 的正整数。要求全部储存在数组中，去除掉不是质数的数字，依次输出剩余的质数。

## 输入格式

第一行输入一个正整数 n，表示整数个数。

第二行输入 n 个正整数 ai​，以空格隔开。

## 输出格式

输出一行，依次输出 ai​ 中剩余的质数，以空格隔开
```c

#include<iostream>
using namespace std;

int main(){
    int n;
    cin >> n;
    int a[100];
    int m;
    int o = 0;//记录质数的个数
    
    for(int i = 0; i < n; i++){
        cin >> m; // 依次读入这 n 个数字
        
        int s = 0;
        // 【优化】判断质数只需要从 2 遍历到 sqrt(m) 即可，效率提升极大！
        for(int t = 2; t * t <= m; t++){ 
            if(m % t == 0){
                s++;
            }
        }
        
        // 【修复】加上 m > 1，排除数字 1 的干扰
        if(s == 0 && m > 1){ 
            a[o] = m;
            o++;
        }
    }

    for(int i = 0; i < o; i++){
        cout << a[i] << " ";
    }
    return 0;
}
```
