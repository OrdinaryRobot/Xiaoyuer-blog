# 二分查找 · 从零到会用

> 尽量用大白话 + 大量注释。目标是：**先看懂「二分是干嘛的」，再记住一个能套的模板。**

## 一、二分到底在解决什么问题

先别管代码，想一个生活场景：

> 你要在「一本按拼音排好序的字典」里查一个字。
> 你不会从第一页一页一页翻（那太慢，要翻几百次）。
> 你会**从中间翻开**，看这个字在中间这页的「前面」还是「后面」，
> 然后把范围砍掉一半，继续翻中间……

这个「**每次砍一半**」的查法，就是二分。

**核心前提：数据必须是有序的（排好序的）。**
- 乱序的字典没法二分（中间那页的字没法告诉你该往左还是往右）。
- 所以二分之前，常常要先 `sort`。

**核心优势：快。**
- 一页页翻：查一个字最多翻 `n` 次。
- 二分：每次砍一半，查一个字最多 `log₂(n)` 次。
- n = 100万 时，一页页翻要 100万次，二分只要约 20 次。天壤之别。

## 二、一个生活化的例子先建立直觉

数组（已经排好序）：`1 3 5 7 9 11 13`

我要找 `7` 在不在里面、在哪个位置。

```
[1 3 5 7 9 11 13]
 ↑      ↑       ↑
 L      mid     R        ← L=左边界，R=右边界，mid=中间

mid = (L+R)/2 = 位置3，值是 5
5 < 7  → 说明 7 在右边 → 把 L 挪到 mid+1

[1 3 5 7 9 11 13]
        ↑  ↑    ↑
        L  mid  R        ← 范围缩小到 [7 9 11 13]

mid = 位置5，值是 9
9 > 7  → 说明 7 在左边 → 把 R 挪到 mid-1

[1 3 5 7 9 11 13]
        ↑ ↑
        L R              ← 范围缩小到 [7]

mid = 位置4，值是 7
7 == 7 → 找到了！位置 4
```

看明白了吗？**每次取中间，比一下，砍掉一半范围。**

## 三、二分查找的「标准模板」（先背这一个）

```cpp
// 在「已经排好序」的数组 a[0..n-1] 里，找等于 x 的下标
// 找不到返回 -1
int binary_search(int a[], int n, int x){
    int L = 0, R = n - 1;      // 左右边界（闭区间 [L, R]）
    while(L <= R){             // 区间非空就一直找
        int mid = (L + R) / 2; // 中间位置
        if(a[mid] == x){
            return mid;        // 找到了，返回下标
        }else if(a[mid] < x){
            L = mid + 1;       // x 更大，去右半边
        }else{
            R = mid - 1;       // x 更小，去左半边
        }
    }
    return -1;                 // 区间找完了都没有 → 不存在
}
```

**逐行注释（这 5 行是灵魂）：**

```cpp
int L = 0, R = n - 1;   // [L, R] 是一个「闭区间」，表示"还没找的范围"
while(L <= R){          // L > R 时说明范围空了，没找到
    int mid = (L + R) / 2;  // 取中点
    if(a[mid] == x) return mid;   // 命中，直接返回
    else if(a[mid] < x) L = mid + 1;  // 目标在右边 → 左边界右移
    else               R = mid - 1;   // 目标在左边 → 右边界左移
}
```

## 四、最容易翻车的 3 个坑（哥你要特别注意）

### 坑 1：`mid = (L + R) / 2` 可能溢出

当 `L` 和 `R` 都很大（比如 20 亿），`L + R` 会超过 `int` 范围。

**安全写法**：

```cpp
int mid = L + (R - L) / 2;   // 等价于 (L+R)/2，但不会溢出
```

（你之前踩过 `int` 溢出的坑，这里同理，但一般入门题 L、R 很小，用 `(L+R)/2` 也够。先记着有这个坑。）

### 坑 2：边界写错（`L = mid` 还是 `L = mid+1`）

这是二分最经典的死循环陷阱。**记住这条铁律：**

> `L` 和 `R` 每次必须「收缩」，不能原地不动。
> - 往右找 → `L = mid + 1`（不是 `mid`）
> - 往左找 → `R = mid - 1`（不是 `mid`）

如果写成 `L = mid` 且 `mid = L` 时，`L` 就卡住不动了，死循环。

### 坑 3：数据没排序就二分

二分**必须在有序数组上**。乱序数组二分结果完全不可靠。所以：

```cpp
sort(a, a + n);   // 先排序，再二分
```

## 五、二分答案（进阶，但新生杯可能考）

二分除了「找一个数」，还能「**猜答案**」。

**场景**：题目问「最小的满足条件的 X 是多少」，而 X 越大越容易满足（单调性），
就可以用二分去「猜」这个 X，每次 O(n) 判断猜的对不对。

**典型例子（你熟悉的前缀和思路串起来）：**

> 有 n 根木头，长度分别为 a[i]，要切成 k 段**等长**的木棍，
> 问每段**最长**能切多长？

思路：每段长度越大，能切出的段数越少（单调递减）。
所以「猜一个长度 L，看能不能切出 ≥k 段」，用二分找最大的 L。

```cpp
// 判断「每段长度 len」时，能切出多少段
bool check(long long len, long long a[], int n, int k){
    long long cnt = 0;
    for(int i=0;i<n;i++){
        cnt += a[i] / len;   // 第 i 根能切出 a[i]/len 段
    }
    return cnt >= k;   // 段数够不够
}
```

**二分答案模板**（这个先了解，真考到了再深入）：

```cpp
long long L = 1, R = 最大可能长度, ans = 0;
while(L <= R){
    long long mid = (L + R) / 2;
    if(check(mid, a, n, k)){   // mid 这个长度可行
        ans = mid;             // 记录当前答案
        L = mid + 1;           // 试着再长一点
    }else{
        R = mid - 1;           // 太长切不够，缩短
    }
}
cout << ans;
```

## 六、STL 帮你二分（`lower_bound` / `upper_bound`）

其实 C++ 的 STL 已经写好了二分，你不用自己写：

```cpp
#include<bits/stdc++.h>
using namespace std;
int a[100] = {1, 3, 5, 7, 9};
int n = 5;

// lower_bound(a, a+n, x)：返回「第一个 >= x」的位置（指针）
int pos = lower_bound(a, a+n, 7) - a;   // pos = 3（7 在位置 3）

// upper_bound(a, a+n, x)：返回「第一个 > x」的位置
int pos2 = upper_bound(a, a+n, 7) - a;  // pos2 = 4（9 在位置 4）

// 用 lower_bound 判断 x 在不在数组里：
int idx = lower_bound(a, a+n, x) - a;
if(idx < n && a[idx] == x) cout << "找到了";
```

**记住**：`lower_bound(a, a+n, x) - a` 得到的是下标（还记得 `unique - a` 那个「指针减数组名 = 下标」的套路吗？一模一样）。

## 七、口诀总结

> **有序才二分，取中砍一半；**
> **大了左边界右移，小了右边界左移；**
> **边界要收缩，`mid±1` 别写错。**
