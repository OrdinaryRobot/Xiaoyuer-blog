# P1781 宇宙总统

## 题目描述

地球历公元 6036 年，全宇宙准备竞选一个最贤能的人当总统，共有 $n$ 个非凡拔尖的人竞选总统，现在票数已经统计完毕，请你算出谁能够当上总统。

## 输入格式

第一行为一个整数 $n$，代表竞选总统的人数。

接下来有 $n$ 行，分别为第一个候选人到第 $n$ 个候选人的票数。

## 输出格式

共两行，第一行是一个整数 $m$，为当上总统的人的号数。

第二行是当上总统的人的票数。

## 输入输出样例 #1

### 输入 #1

```
5
98765
12365
87954
1022356
985678

```

### 输出 #1

```
4
1022356
```

## 说明/提示

$1 \leq n \leq 20$。

票数可能会很大，可能会到 $100$ 位数字。数据保证不存在票数相同的候选人。

答案
```c
#include<bits/stdc++.h>
using namespace std;
long long a[25];
long long vote[1000005];
int main(){
    int n;
    cin>>n;
    string best;//准备好，读取最终答案
    int id=1;//第一个先上
    
    for(int i=1;i<=n;i++){
        string s;
        cin>>s;//存票数
        bool bigger=false;//判断谁大
        
        if( s.size()>best.size()) bigger=true;
        else if(s.size()==best.size() && s>best ) bigger=true; 

        if(bigger){
            best=s;
            id=i;
        }
    }
    cout<<id<<'\n'<<best;
    return 0;
}
```
