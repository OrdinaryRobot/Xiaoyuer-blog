## 一、贪心到底是什么

一句话：**每一步都选「当前看起来最好的」，不回头、不考虑以后。**

就像你在食堂打饭，每次都挑「最快那个窗口」——你不管下一个窗口会不会更快，
只管现在这个选择最好。这种「只看眼前、贪当下」的思路，就是贪心。

**贪心的两个关键：**

1. **局部最优**：每一步都选当前最优的选择。
2. **不后悔**：选完就不改，一路走到底。

**贪心能不能用，取决于「局部最优」能不能推出「全局最优」。**
不是所有题都能贪心，但能贪的题，代码往往特别短。

## 二、用你做过的 P1223 排队接水来理解

**题目回顾**：n 个人接水，第 i 人用时 t[i]，问怎么排队让「总等待时间」最小。

**贪心选择**：用时短的人排前面。（你当时想「最快的排第一个就够了」——我们后来纠正成「全体从小到大排」。）

**为什么「短的在前」是贪心？**
每一步（决定下一个人排谁），都选「剩下的人里用时最短的那个」→ 这就是局部最优。
而局部最优累加起来，恰好就是全局最优（总等待最小）。

**代码（你熟，加点注释）：**

```cpp
#include<bits/stdc++.h>
using namespace std;
pair<int,int> p[1005];   // first=接水时间，second=编号
int main(){
    int n; cin >> n;
    for(int i=1;i<=n;i++){
        int t; cin >> t;
        p[i] = {t, i};   // 把时间和编号绑一起（pair，你学过了）
    }
    sort(p+1, p+n+1);    // 按时间从小到大排（贪心：短的在前）

    double sum = 0, wait = 0;
    for(int i=1;i<=n;i++){
        cout << p[i].second << " ";   // 输出顺序（编号）
        sum += wait;                   // 这个人要等前面所有人
        wait += p[i].first;            // 累加当前这个人的时间
    }
    cout << '\n';
    printf("%.2f", sum / n);          // 平均等待时间
    return 0;
}
```

**贪心点就一句**：`sort(p+1, p+n+1)` —— 把用时短的排前面，就是这题的贪心。

## 三、用你做过的 P1208 混合牛奶来理解

**题目回顾**：要凑够 n 单位牛奶，有 m 个奶农，每个提供（单价, 数量）。问最少花多少钱。

**贪心选择**：按**单价从低到高**买，单价便宜的奶农先买光。

**为什么？** 你想花最少的钱，那每一份牛奶都尽量买「最便宜的那个来源」。
所以把奶农按单价排序，从最便宜的开始买，买够 n 就停。

**代码（pair 版，你之前踩过「sort 拆散单价数量」的坑）：**

```cpp
#include<bits/stdc++.h>
using namespace std;
pair<long long,long long> c[5005];  // first=单价，second=数量
int main(){
    long long n, m; cin >> n >> m;
    for(int i=0;i<m;i++)
        cin >> c[i].first >> c[i].second;   // 单价+数量绑一起

    sort(c, c+m);   // 按 first(单价) 从低到高（贪心：先买便宜的）

    long long mon = 0;
    for(int i=0;i<m && n>0;i++){
        long long buy = min(n, c[i].second);  // 能买多少买多少
        mon += c[i].first * buy;
        n -= buy;
    }
    cout << mon;
    return 0;
}
```

**贪心点就一句**：`sort(c, c+m)` 按单价排，然后从头买到尾。

## 四、贪心题的「通用解题套路」（四步法）

你做过的这两题，其实都走同一个套路。抽象出来：

1. **确定「贪心标准」**：按什么排序/选什么？
   - P1223：按「时间」排（短的在前）
   - P1208：按「单价」排（便宜的在前）

2. **排序**：用 `sort`（配合 `pair` 或自定义 `cmp`）把数据按贪心标准排好。

3. **贪心处理**：从头扫到尾，每次做「当前最优」的选择，累加结果。

4. **输出答案**。

**记住这个骨架：**

```cpp
// 1. 读入 + 绑成 pair/结构体
// 2. sort 排序（按贪心标准）
// 3. for 从头扫，贪心选，累加
// 4. 输出
```

## 五、贪心最常见的「标准」：区间调度

新生杯贪心最爱考的一种，叫**区间调度**（活动安排）：

> 有 n 个活动，每个有开始时间 s[i] 和结束时间 f[i]。
> 同一时间只能做一个活动，问最多能做几个活动？

**贪心标准：按「结束时间」从早到晚排，每次选「结束最早且不冲突」的活动。**

**为什么按结束时间，不按开始时间？**
结束得早，就能给后面腾出更多时间 → 能做更多活动。这就是贪心的「局部最优」。

```cpp
#include<bits/stdc++.h>
using namespace std;
pair<int,int> a[1005];  // first=结束时间，second=开始时间
int main(){
    int n; cin >> n;
    for(int i=0;i<n;i++){
        int s, f; cin >> s >> f;
        a[i] = {f, s};   // 注意：first 存结束时间，方便 sort 按结束排
    }
    sort(a, a+n);   // 按结束时间从早到晚

    int cnt = 0, last = -1;   // last = 上一个选中活动的结束时间
    for(int i=0;i<n;i++){
        if(a[i].second >= last){  // 这个活动的开始时间 >= 上一个的结束（不冲突）
            cnt++;
            last = a[i].first;    // 更新 last 为这个活动的结束时间
        }
    }
    cout << cnt;
    return 0;
}
```

**贪心点**：`sort(a, a+n)` 按结束时间排，然后能选就选。

## 六、贪心 vs 其他算法（一句辨别）

- **贪心**：每步选当前最优，一步到位，不回头。
- **动态规划**：会「考虑以后」，可能当前选差的、后面反而更优。
- **暴力枚举**：所有可能都试一遍。

判断能不能用贪心的关键：**「当前最优」是否等于「全局最优」？**
是 → 贪心；不确定 → 别贪，可能要枚举/DP。

## 七、口诀总结

> **贪心四步：定标准、先排序、从头扫、累答案。**
> **区间调度按结束排，买牛奶按单价排，接水按用时排。**
> **能贪就贪，不能贪别硬贪。**
