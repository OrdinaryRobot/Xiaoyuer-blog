**先点题，Bool只要条件为真，那么就只会记录一次，不会再测**
**而对于t++这种累加，如果出现同一个真被多个条件凑出来，则会累计计数**


# P2141 [NOIP 2014 普及组] 珠心算测验

随机生成一个正整数集合，集合中的数各不相同，然后要求学生回答：其中有多少个数，恰好等于集合中另外两个（不同的）数之和？
你帮忙求出答案。

## 输入格式

共两行，第一行包含一个整数 $n$，表示测试题中给出的正整数个数。

第二行有 $n$ 个正整数，每两个正整数之间用一个空格隔开，表示测试题中给出的正整数。
## 输出格式

一个整数，表示测验题答案。
### 输入 #1

```
4
1 2 3 4
```

### 输出 #1

```
2
```

## 说明/提示


由 $1+2=3,1+3=4$，故满足测试要求的答案为 $2$。  

注意，加数和被加数必须是集合中的两个不同的数。
【数据说明】


对于 $100\%$ 的数据，$3 \leq n \leq 100$，测验题给出的正整数大小不超过 $10,000$。
```c
#include<bits/stdc++.h>
using namespace std;
int a[1000];
int main(){
    int n;
    cin>>n;
    for(int i=0;i<n;i++){
        cin>>a[i];
    }
    int t=0;
    for(int i=0;i<n;i++){
        bool ok=false;
        for(int j=0;j<n;j++){
            for(int k=0;k<n;k++){
                if(j!=k && i!=j && k!=j && a[j]+a[k]==a[i] ) ok=true;
                }
            }
        if(ok) t++;
        }
    
        
    cout<<t;
    return 0;
}
```
