**1.函数概念**
函数实际上是一个小程序，里面包装了预先写好的代码，用于减少重复代码的书写：
         such as：main，scanf，printf

**2.函数的形式**
数据类型+函数名+（参数）
 *(void)表示没有参数
```c
int name(int x, int y)//函数头
{
return x+y;//函数体
}
```

**3.库函数**
 * 预先写好，包装好的函数，被集中放在库文件中，配有说明书‘头文件’
  * 一般被编译器厂商放在自家编译器中
  
  **4.自定义函数**
      一串代码
  ```c
  #include<stdio.h>
//定义函数
int average( int x , int y )
{
    int z=(x+y)/2;

    return z;
}
int main(){

    int a,b;
    
    scanf("%d %d",&a,&b);

    int r=average(a,b);
    
    printf("%d",r);

    return 0;

}
  ```
BBB 三目运算符 *设计可以判断最大值的函数以及简化代码

### 参数
 **形参和实参**

- 形参，即定义函数时的参数（int x,y),他们在不被调用存储实参时，不会申请占用内存，他们不是真实存在的
- 实参，即传递给函数的参数（如a，b），他们是实际存在的
