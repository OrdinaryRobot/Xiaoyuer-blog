## pair
###### pair是一个可以将两个元素统一在一个数组同一个位置的数据类型（容器）
*可代替二元结构体*
它的形式为
```c
pair<int,int>p[100];
```
通常用于给两个绑定的数值排序（如比较并输出人花费的时间以及他的编号）
（**数据类型可以不同**

**对于排序**
sort函数排序会优先看第一位数字，也就是p.first，如果一位数字相同，那么就去比较二位数字
它的形式
```c
sort(a,a+n);
```
###### 访问
```c
cout<<p[0].first;
```
  
## unique

unique(独一无二),如同它的名字，它是一个指针（迭代器）  
可以为一组相邻数据去重，并返回最后一个元素的**下一个位置**

###### **使用条件**

它只会去掉相邻的重复元素，使用前务必排序！（sort）

_形式如下_

```c
int a[6]={1,1,2,3,4,4};
int m=unique(a,a+n);//它会输出一个地址：形如 0x7ffe3a2b1c18
```

_要输出有多少个数的话_，则

```c
int m=unique(a,a+n)-a;
```

首末地址相减才得个数

## getline

读一整行（含空格），遇到换行才停。

```c
string s;
getline(cin, s);   // 读一行到 s
```

与 `cin >> s` 的区别：`cin >>` 读到空格就停，`getline` 空格也算字符。

> ⚠️ `cin >> n` 后再 `getline`，要先用 `getchar()` 或 `cin.ignore()` 吃掉残留换行符。

## string（容器）

字符串类。它下面挂着一堆**成员函数**（分支），都要用 `s.xxx()` 调用。

### 常用成员函数（string 的分支）

| 函数                  | 作用                      | 例子                              |
| ------------------- | ----------------------- | ------------------------------- |
| `s.size()`          | 长度                      | `"abc".size()` → 3              |
| `s.empty()`         | 是否为空                    | `"".empty()` → true             |
| `s[i]`              | 取第 i 个字符                | `s[0]`                          |
| `s.substr(起点[,长度])` | 截取子串                    | `"123456".substr(2)` → `"3456"` |
| `s.find(子串[,起点])`   | 查找，找不到返回 `string::npos` | `s.find('.')`                   |
| `s.erase(起点,个数)`    | 删字符                     | `s.erase(0,1)` 删第 0 个           |
| `s.pop_back()`      | 删最后一个字符                 | 去末尾 0                           |
| `s.back()`          | 取最后一个字符                 | `s.back()`                      |
| `s.push_back(字符)`   | 末尾加字符                   | `s.push_back('a')`              |
### substr

用法：s.substr（起点），s.substr（起点，长度）
解析：>>1.对于 s. substr（起点）,它会从字符串中起点所设置的位置开始截取字符，直到终点
      例如一个12345的字符串，我们用s.substr(1)，即从数组第一位（实际第二位）开始截取，得到2345
     >> 2.对于s.substr(起点，长度),在1的基础上，限定了截取的长度，同样对于12345，我们用substr(1,2),我们得到23
### find

用法：s.find('字符/串'，（起点）)
解析：find，可以帮我们找到字符串里面我们想要得到的子串，它会返回子串的起始位置
      >>例如一个字符串” wo xing hao mei xue yi “，我们要找到”xue“，只需s.find(" xue ")
      就会得到16（即数组第16位）
      >>再如一个字符串”ji suan ji suan ji“，要找到第二个suan，只需s.find(" suan ",3)
      <其实起点只要错过前面的suan的地址就行>,就会输出10
      
### 字符串比较

- `s1 == s2`、`s1 > s2`、`s1 < s2`：按字典序比较。
- **数字字符串**比大小要特殊：先比长度，同长再比字典序（如 P1781 宇宙总统）。

### 反转（注意：reverse 是算法，不是 string 成员）

```c
reverse(s.begin(), s.end());   // 反转整个字符串
```

> `reverse` 前面**没有** `s.`，它是独立的算法函数，不专属于 string。
