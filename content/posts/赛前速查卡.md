## 2. 五个高频坑（背口诀）

| 坑 | 口诀 | 栽过的题 |
|---|---|---|
| 数组越界 | 「0 到 L 是 **L+1** 个」→ 循环 `i<=L`，数组开 `L+1` | 校门外的树 P1047 |
| 循环次数 | 读 m 组用 `i<m`；**数位置**才考虑 `<=` | 校门外的树 P1047 |
| int 溢出 | 累加、乘法、年份秒数 → 先想 `long long` | 求区间和、时光的数字密语 |
| 循环变量打架 | 循环里别改 `i`，别拿 `a` 当 `i` 用；**行和列别混** | 整数报数、走网格 |
| 局部变量裸奔 | `int x = 0;` 声明即初始化（**只有全局**才自动为 0） | 走网格（编译警告） |

**顺带三条常忘的：**

- 字符串里存的是**字符**不是数字：`s[i]-'0'` 转数字，整串转整数用 `val = val*10 + (s[i]-'0')`
- 读一整行（含空格）用 `getline(cin, s)`；`cin >>` 之后残留的换行用 `cin.ignore()` 吃掉
- 数字字符串比大小：**先比长度，同长再比字典序**（宇宙总统 P1781）
- `endl` / `printf` 是**输出**，`cin` / `getline` / `getchar` / `cin.ignore()` 才是**读入**

## 4. 能直接默写的模板片段

### 前缀和

```cpp
long long a[100005], sum[100005];
cin >> n;
for(int i=1;i<=n;i++){ cin >> a[i]; sum[i] = sum[i-1] + a[i]; }   // 注意 <=n
cin >> m;
while(m--){ int l,r; cin >> l >> r; cout << sum[r] - sum[l-1] << '\n'; }
```

### pair 绑定排序（两个值必须一起动）

```cpp
pair<int,int> p[1005];
p[i] = {时间, 编号};          // first 放排序关键字
sort(p+1, p+n+1);            // 先比 first，相等再比 second
cout << p[i].second;         // 数组必须带下标 [i]
```

### 排序 + 去重

```cpp
sort(a, a+n);
int m = unique(a, a+n) - a;  // 先 sort 再 unique；-a 不能省
```

### 区间调度贪心（按结束时间排）

```cpp
a[i] = {r, l};               // first = 结束时间
sort(a, a+n);
int last = -1, cnt = 0;
for(int i=0;i<n;i++)
    if(a[i].second >= last){ cnt++; last = a[i].first; }
```

### 枚举 + bool 去重计数（珠心算 P2141）

```cpp
for(int k=0;k<n;k++){
    bool ok = false;                       // 记「这个数能不能被凑出来」
    for(int i=0;i<n;i++)
        for(int j=0;j<n;j++)
            if(i!=j && a[i]+a[j]==a[k]) ok = true;
    if(ok) ans++;                          // 循环外加，只算一次
}
```

### 网格 8 方向（下标从 1 开始，多开一圈）

```cpp
char c[1005][1005];
for(int i=1;i<=n;i++)
    for(int j=1;j<=m;j++) cin >> c[i][j];

for(int x=i-1;x<=i+1;x++)
    for(int y=j-1;y<=j+1;y++)
        if(c[x][y]=='*') cnt++;
// 边缘那一圈是 '\0'，不会误判，不用写越界判断
```

### 对齐输出 / 每行 5 个

```cpp
printf("%5d", i);            // 占 5 列右对齐，等价于 setw(5)
if(++t == 5){ printf("\n"); t = 0; }
if(t != 0) printf("\n");     // 最后一行没满 5 个才补换行
printf("Sum = %d", sum);
```

### 字符串转整数 / 字符判断

```cpp
getline(cin, s);                          // 读整行（含空格）
int val = 0;
for(int i=0;i<s.size();i++){
    if(s[i] < '0' || s[i] > '9') { /* 非法 */ }
    val = val*10 + (s[i]-'0');
}
```

## 7. 三种题型速认（11/13 群消息新增，官方手册未说明）

来源：官方群理事长曹荣智连发「交互题」「通信题」「传统题」，吉祥物接「学会」。
**关键认知：题型 ≠ 算法考点。** 变的只是「数据怎么进怎么出」，算法内核还是模拟、枚举、二分、贪心、前缀和这些，不用推翻重来。

| 题型 | 数据怎么流 | 一句话 | 你的底气 |
|---|---|---|---|
| 传统题 | 输入 → 程序 → 输出 | 一次读完、一次输出 | 主战场，练过的全是它 |
| 交互题 | 程序 ↔ 评测器（多轮问答）| 边问边猜，实时回话 | 《二分查找教程》正好对口 |
| 通信题 | 程序A 读输入 → 少量信息 → 程序B 出答案 | 两台程序分工，信息量受限 | 认识概念即可 |

### 交互题三条铁律（第一杀手是缓冲）

1. **输出必须刷新缓冲**：`cout << "? " << mid << endl;`
   写 `'\n'` 不刷新 → 评测器收不到提问 → 判 Idleness / TLE。
   也可用 `cout << flush;` 或 `fflush(stdout);`。
2. **每问一次必须 `cin >>` 读回答**：问完不读，程序空等。
3. **提问次数有上限** → 不能逐个试，必须**二分**。

最小骨架（`?` 提问、`!` 报答案只是常见约定，**格式一律以题面为准**）：

```cpp
int l=1, r=n;
while(l<r){
    int mid=(l+r)/2;
    cout << "? " << mid << endl;      // endl 会 flush，别写 '\n'
    string ans; cin >> ans;
    if(ans=="<=") r=mid; else l=mid+1;
}
cout << "! " << l << endl;
```

本地无法自测（没有评测器陪跑），只能在 OJ 交。

### 通信题要点

- 通常交**两份程序**（或一份代码分两个角色，看题面）：
  - A：能读全部输入，但只能传出**有限信息**（题面会写「最多 k 个字符 / bit」）
  - B：读不到原始输入，只能靠 A 传来的信息输出最终答案
- 考点是「怎么把最关键的一丁点压缩传过去」：常见套路传奇偶性、传一个下标、传校验值。
- 别想「A 直接把答案算完传过去」——信息量根本不够。
- ⚠️ 本 OJ 具体提交形式（两份代码 / 单份分角色）**未确认**，现场看题面通信协议段或问工作人员。

### 现场 4 个动作

1. 先找题面有没有「本题为交互题 / 通信协议」小节，有就先读那段
2. 数清楚**要交几份代码**、每份分别读什么
3. 交互题提交前自检：每个输出后面 `endl` 没、每次输出后面有没有对应读入
4. 别用「一口气输出全部答案」的传统题思路写

> **endl、读了再问、二分。**
